Claude Sonnet 5 agent autonomously selects and delivers gene therapy in live mouse brain surgery

What happened

A Claude Sonnet 5-powered agent, given a list of 19 gene therapies, an epilepsy mouse model, and control of a motorized surgical rig with cameras, independently selected a gene therapy targeting an inhibitory signaling pathway, chose the brain region and stereotactic injection coordinates derived from multiple papers, and executed the injection procedure. The agent made 32 real-time observations during the surgery. When it detected a calibration error, it refused to continue rather than violate safety limits. A veterinarian approved irreversible steps.

Safety

The agent demonstrated built-in safety behaviors by refusing to continue on detection of a calibration error. A veterinarian was required to approve irreversible steps. This is reported as the first instance of an AI agent both selecting and physically delivering a treatment to a living mammal with no human decision-making in the selection or targeting steps.

Use case

Autonomous AI agents performing high-stakes biological procedures with real-time observation, reasoning from scientific literature, and hard safety stops.

So what

This demonstrates advanced autonomous reasoning in a high-stakes biological context while showing built-in safety behaviors. It marks a milestone in AI agents operating directly on living mammals with minimal human oversight.

Google makes Gemini API Computer Use generally available

What happened

Google announced that Computer Use (browser and UI automation capabilities) for the Gemini API has exited preview and is now generally available for production use.

Safety

Moving agentic browser and desktop automation from experimental to production requires careful deployment controls and monitoring to prevent misuse at scale.

Use case

Developers can now build and deploy production autonomous agents that interact with web interfaces and desktop environments using the Gemini API.

So what

A powerful agentic capability has moved from experimental to production-ready, potentially accelerating development of autonomous AI agents at scale.

OpenAI tightens weapons and violence-related restrictions for teen users on ChatGPT

What happened

OpenAI announced new safeguards: it will restrict practical information on weapons and security systems for users identified as teens (even without evident harmful intent), automatically end chats showing fixation on violence (for all users), strengthen age estimation to route under-18s to teen safeguards, notify parents of repeated violence-related pauses, and limit details on past mass attacks.

Safety

This is a significant expansion of proactive safety measures aimed at preventing real-world violence and protecting younger users. It includes stronger age estimation, automatic chat termination on violence fixation, and parental notifications.

Use case

Teen users of ChatGPT now receive heightened safeguards against weapons and violence-related content. All users benefit from automatic termination of chats showing fixation on violence.

So what

OpenAI is expanding proactive safety measures amid increasing regulatory and societal scrutiny of AI's potential role in enabling harm.

Major AI companies back shared robots.txt signal for AI training opt-out

What happened

OpenAI, Google, Microsoft, and Anthropic announced support for a new common "policy token" signal in robots.txt. This allows website operators to express preferences about use of their content for AI training with one standardized entry instead of separate rules for each company's crawler.

Safety

This voluntary industry standard improves respect for content creators' preferences at web scale and simplifies compliance for publishers.

Use case

Website operators can now use one standardized robots.txt entry to signal opt-out preferences to multiple major AI companies' crawlers.

So what

The collaboration represents industry alignment on a voluntary standard (proposed via IETF) that simplifies compliance and better respects creator preferences at web scale.

Source: openai.com

Microsoft open-sources TokenEconomizer for coding agent cost reduction

What happened

Microsoft Research and UC Berkeley released TokenEconomizer, an open-source plugin that learns from past repository sessions to reduce token waste in future coding-agent runs. It achieved 18.4%-30.9% mean cost reduction across tested agent-model combinations on SWE-Bench tasks without changing model weights or core agent code.

Safety

No direct safety implications. The tool focuses on efficiency of existing coding agents.

Use case

Developers running coding agents on repositories can plug in TokenEconomizer to automatically reduce token usage and cost on subsequent runs.

So what

Practical efficiency improvements for agentic coding workflows can lower operational costs substantially, making advanced AI software engineering tools more accessible and sustainable.

Source: blog.jiufeng.ai (citing Microsoft GitHub repo and arXiv paper)
