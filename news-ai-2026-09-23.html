CLOSEDQUORUM: malware that asks four AIs what to steal next

What happened

Cisco Talos disclosed CLOSEDQUORUM — a Go-based Windows implant it calls the first publicly documented malware to treat commercial LLMs as command-and-control. After install, it queries up to four providers (DeepSeek, Qwen, Mistral, Google Gemini), tallies their votes, and runs the winning action. No human operator on the loop. No attacker-run C2 server.

Same day Talos open-sourced CAIRN, a toolkit for hunting AI-integrated malware. The public distribution binary ships with dummy API keys (inert as found). Development builds show per-operator keys and a Discord webhook injected at compile time. Artifacts link the developer to carding-forum posts dating to 2025. Talos has not confirmed in-the-wild live campaigns.

Safety

The system prompt extracted from the binary: “You are an advanced malware strategist. Provide ONLY executable decisions.” Allowed moves are a short schema — steal, inject, persist, move. Steal dumps LSASS, browser passwords (Chrome / Edge / Firefox), and crypto wallets (MetaMask, Exodus, Ethereum paths). Inject uses process hollowing or Early Bird APC. Persist hits registry run keys, scheduled tasks, and WMI.

Tie-break order is hardcoded: DeepSeek first, then Qwen, Mistral, Gemini. Exfil goes AES-256-GCM to Discord. C2 traffic looks like ordinary AI API calls — the part defenders usually block as “suspicious domain” disappears. One year, Talos says, from “LLM as optional helper” to “fully autonomous multi-model orchestrator.”

Use case

Named defensive use, not vapor: CAIRN is public for researchers hunting the same class. Detection angles Talos flags — unexpected Windows binaries hitting several LLM providers in a short window, plus LSASS / injection / Discord webhook behavior from the same host. Palo Alto Unit 42 separately shipped Continuous Frontier AI Defense this week; the industry is building harnesses against agentic offense while labs cut model prices.

So what

Yesterday’s story was cheaper frontier models with tighter cages. Today’s story is malware that rents those cages as a voting board and keeps running while the attacker sleeps. The implant is early and limited. The architecture is the news: ordinary API access plus a constrained decision schema is enough to remove the human from a phase of the intrusion.

If you run detection, CAIRN is the homework. If you ship agents, this is why “the model left the cage” and “the malware called four models” are the same week. Watch whether live campaigns show up with real keys — and whether providers start rate-limiting or refusing prompts that look like CLOSEDQUORUM’s strategist schema.
